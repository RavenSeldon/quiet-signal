## Verification performed

- 14 Python test methods, including 36 exact rational oracle comparisons.
- 640 Python/browser expectation comparisons and 35,840 deterministic traces.
- Exact random-policy evaluation by summing all query orders, not sampling.
- Complete sensitivity-grid budget and optimal-dominance assertions.
- Chromium UI checks: replay, manual budget refusal, complementary silence and
  paired signals, closed gate, high cost, zero budget, random full budget,
  new-world reset, research note, no runtime errors or external requests.
- Desktop and mobile screenshots visually inspected. Layout checked at widths
  320, 390, 768 and 1440 pixels. Keyboard range navigation and reduced motion checked.
- Asset SHA-256 verification and inherited-source ledger verification.
- All seven primary outputs repeated byte for byte in the isolated environment;
  all 74,240 metric cells agreed across two NumPy installations within 1.43e−14,
  below the declared 1e−10 numerical tolerance.

The suite is written and executed by the same assistant as the implementation.
“Independent rational oracle” means a separate arithmetic and search implementation;
it does not mean an independent scientist reviewed the work. The original brief's
independent-collaborator gate is interpreted as reproducibility readiness, not a
fabricated claim that another person has run it.

## Deliberately deferred

External replication, screen-reader evaluation, human comprehension testing,
misspecified models, multistep tasks, learned allocation, compute-cost measurement,
compression, scientific publication, hosted deployment and Sīdus integration.
The prototype's current claims do not require those extensions.
